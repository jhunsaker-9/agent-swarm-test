# Agent Swarm Test Project

This is a dummy repository for testing the agent orchestration system.

## Purpose
- Practice agent spawning in worktrees
- Test branch protection rules
- Validate PR workflow (feat → staging → main)
- Ensure agents stay within guardrails

## Structure
Simple Node.js/TypeScript project with:
- Basic Express API
- A few endpoints to modify
- Tests to validate changes
- Simple enough to complete quickly

## Workflow
1. Josh shares requirements
2. Lan scopes the task
3. Agents work in parallel
4. PRs opened to staging
5. Josh reviews and merges
